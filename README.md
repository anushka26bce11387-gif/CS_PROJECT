# Student Performance and Attendance Analytics System

## Project Description

A Python and SQLite-based application for managing student records, attendance, academic performance, and analytics.

## Features

* Add, search, update, and delete students
* Manage attendance records
* Calculate attendance percentage
* Manage performance records
* Calculate performance percentage
* View student and class analytics
* Generate student reports
* Input validation and error handling

## Technologies

* Python 3
* SQLite
* SQL
* VS Code

## How to Run

Open the `CS_PROJECT` folder in VS Code and run:

```bash
python main.py
```

## Database

SQLite is used to store student, attendance, and performance data.
